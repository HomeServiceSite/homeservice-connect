Frequently asked questions

Good to know

Some quick answers about using White Mountain Home Services.

Is it free to request a quote?

Yes. Homeowners can submit a project request without paying a fee to use the quote request form.

How do I find a contractor?

Use the contractor directory to explore participating businesses, or submit a project request so we can look for a potential match.

Are all contractors automatically approved?

No. Contractor applications are reviewed before a business is added to the participating contractor network.

What if no contractor matches my request?

Availability depends on the services and areas covered by participating contractors. If no match is available, you can try again later as the network grows.

Can businesses outside Show Low apply?

Yes. Businesses serving the White Mountains and surrounding communities are welcome to apply.
